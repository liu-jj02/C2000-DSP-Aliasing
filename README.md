# C2000-DSP-Aliasing

DSP 学习计划 W2 的实验：用 MATLAB 复现采样定理与混叠现象，并验证混叠的**不可逆性**。

## 实验内容

| 编号 | 实验 | 参数 | 结果 |
|---|---|---|---|
| A | 正常采样 | f0 = 1000 Hz, fs = 10 kHz | 波形完整，2 ms 内 2 个周期 |
| B1 | 欠采样波形 | f0 = 1000 Hz, fs = 1200 Hz | 采样点仍在 1 kHz 正弦上，连起来却像 200 Hz |
| B2 | 频谱分析 | 同上 | 频谱出现 200 Hz 的峰（= \|1000 − 1200\|） |
| B3 | 不可逆性验证 | 同上 | 1000 Hz 与 −200 Hz 产生同一组采样点 |
| C | 幻影频率 vs 采样率 | fs 从 200 Hz 扫到 10 kHz | 锯齿曲线，齿尖在 fs = f0/k 处（混叠为 0） |

## 关键结论

1. **混叠的本质是频率折叠**：高于 fs/2 的成分不会消失，而是折回 [0, fs/2] 区间
2. **相位会反转**：1000 Hz 在 fs = 1200 Hz 下表现为 **−200 Hz**，即 180° 反相
3. **不可逆**：200 / 1000 / 1400 / 2600 Hz 会采出同一组采样点，是"多对一"映射，无法求逆
4. **工程结论**：抗混叠滤波器必须放在 ADC **之前**（模拟侧），采样之后无法补救

## 文件说明

- `aliasing_demo.m` —— 主脚本，参数集中在开头，一键生成 5 张图
- `01~05*.png` —— 运行结果
- `05_alias_vs_fs.png` 的对数坐标下可以看到齿尖等间距，验证了 fs = f0/k 的规律
- B2中：补零到 1024 点后，频谱曲线看起来"更细更密"了，但峰的位置没变、真正的分辨能力也没变，只是把幅度稀释了 8.5 倍。补零做的是"插值显示"，不是新增信息。

## 环境与运行

- MATLAB R2020a 及以上（用到 `exportgraphics`）
- 直接运行 `aliasing_demo.m`；把 `save_fig` 改成 `true` 可自动保存图片
